# Data dictionary

The authoritative data table is the `Projects` worksheet in `data/ODI_Tracker_latest.xlsx`.

| Field | Meaning |
|---|---|
| Investor/Company Name | Chinese investor, contractor or relevant project entity. |
| Chinese Company Home Province | Mainland Chinese home province, municipality or autonomous region. |
| Announcement Date | Earliest verified qualifying announcement or award date. |
| Announcement date (year-month) | Monthly aggregation key in `YYYY/MM` format. |
| Expected Completion Date | Publicly stated expected completion date, when available. |
| Destination Country/Territory | Project destination. |
| Region / Subregion | Standardised geographic classification. |
| Project Name | Normalised project, transaction or contract name. |
| Primary Investment/Contract Value | Preferred numeric USD value. Project-specific Chinese attributable value is preferred. |
| Secondary Investment/Contract Value | Original-currency value in compact form, such as `CNY277m`. |
| Secondary Investment/Contract Value Note | Qualifiers, allocation caveats, project-total context and other amount information. |
| Primary / Secondary Industry | Standardised two-level industry classification. |
| Primary Category | `Direct Investment` or `Contracted Construction`. |
| Secondary Category | Transaction or contract form, such as greenfield, M&A, EPC or civil works. |
| Note | Concise evidence and classification explanation. |
| Source Webpage URL | One or more supporting public sources. |
| Status | Blank, `Doubtful`, `Cancelled`, `Completed` or `In progress`. |
| Motivation | Market-, resource-, technology- or efficiency-seeking motivation, where classified. |

## Amount policy

An undisclosed amount never causes exclusion. Owner-level project totals, multi-company aggregates and broad industrial-cluster values are not substituted for a Chinese company's attributable investment or contract value unless clearly labelled in the secondary amount note.

## Construction policy

A construction record requires award evidence. A signing report may corroborate an earlier award but cannot independently qualify a project for inclusion.
